# Studio In Prime São Francisco

Landing page estática (HTML, CSS e JavaScript), mobile first, sem etapa de build.

## Estrutura
- `index.html`, `privacidade.html`: páginas
- `styles.css`, `script.js`: estilo e comportamento
- `assets/`: logos, fotos e vídeos
- `vercel.json`: cabeçalhos e cache para deploy na Vercel

## Deploy
Qualquer hosting estático. Na Vercel, o deploy ocorre a cada push na branch `main`.
